┌──────────────────────────────────────────────────────────────────────────────┐
│ METHOD 1: Cross-Compile from Linux/WSL (Recommended)                        │
└──────────────────────────────────────────────────────────────────────────────┘

  STEP 1: Install LLVM-MinGW
  ─────────────────────────────────────────────────────────────────────────────
    wget https://github.com/mstorsjo/llvm-mingw/releases/download/20240917/\
         llvm-mingw-20240917-ucrt-ubuntu-20.04-x86_64.tar.xz
    tar -xf llvm-mingw-20240917-ucrt-ubuntu-20.04-x86_64.tar.xz
    export LLVM_MINGW_ROOT=$PWD/llvm-mingw-20240917-ucrt-ubuntu-20.04-x86_64

  STEP 2: Install Ninja
  ─────────────────────────────────────────────────────────────────────────────
    sudo apt install ninja-build cmake

  STEP 3: Build (ONE COMMAND!)
  ─────────────────────────────────────────────────────────────────────────────
    cd /path/to/rvtt-cpp
    ./build-windows.sh

  DONE! Your executable is at: build-windows/rvtt.exe

┌──────────────────────────────────────────────────────────────────────────────┐
│ METHOD 2: Native Windows Build                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  STEP 1: Install Tools
  ─────────────────────────────────────────────────────────────────────────────
    Download LLVM-MinGW: https://github.com/mstorsjo/llvm-mingw/releases
    Extract to C:\llvm-mingw
    Add to PATH: C:\llvm-mingw\bin

    winget install Ninja-build.Ninja
    winget install Kitware.CMake

  STEP 2: Build (ONE COMMAND!)
  ─────────────────────────────────────────────────────────────────────────────
    cd C:\path\to\rvtt-cpp
    build-windows.bat

  DONE! Your executable is at: build-windows\rvtt.exe

┌──────────────────────────────────────────────────────────────────────────────┐
│ VERIFY YOUR BUILD                                                            │
└──────────────────────────────────────────────────────────────────────────────┘

  Check Static Linking (should only show system DLLs):
  ─────────────────────────────────────────────────────────────────────────────
    Linux:   x86_64-w64-mingw32-objdump -p build-windows/rvtt.exe | grep "DLL"
    Windows: dumpbin /dependents build-windows\rvtt.exe

  Check LTO is enabled:
  ─────────────────────────────────────────────────────────────────────────────
    grep CMAKE_INTERPROCEDURAL_OPTIMIZATION build-windows/CMakeCache.txt
    Should show: CMAKE_INTERPROCEDURAL_OPTIMIZATION:BOOL=ON

  Check file size:
  ─────────────────────────────────────────────────────────────────────────────
    ls -lh build-windows/rvtt.exe    (Linux)
    dir build-windows\rvtt.exe       (Windows)

┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: "LLVM_MINGW_ROOT not set"
  ───────────────────────────────────────────────────────────────────────────── 
    export LLVM_MINGW_ROOT=/path/to/llvm-mingw

  Problem: "PortAudio not found"
  ───────────────────────────────────────────────────────────────────────────── 
    export PORTAUDIO_ROOT=/path/to/portaudio/install
    See: PORTAUDIO_WINDOWS.md for build instructions

  Problem: "Ninja not found"
  ───────────────────────────────────────────────────────────────────────────── 
    Linux:   sudo apt install ninja-build
    Windows: winget install Ninja-build.Ninja

  Problem: Build succeeded but binary is large (>20 MB)
  ───────────────────────────────────────────────────────────────────────────── 
    1. Check: grep CMAKE_INTERPROCEDURAL_OPTIMIZATION build-windows/CMakeCache.txt
    2. Strip: llvm-strip -s build-windows/rvtt.exe
    3. Compress: upx --best --lzma build-windows/rvtt.exe

  Problem: Missing DLLs when running on Windows
  ───────────────────────────────────────────────────────────────────────────── 
    Check if using static PortAudio: ls -la /path/to/portaudio/lib/*.a
    Rebuild PortAudio as static (see PORTAUDIO_WINDOWS.md)
